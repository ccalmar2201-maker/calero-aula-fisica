# Calero Aula · Física y Química (2º ESO)

App web interactiva para repasar **factores de conversión, notación científica,
cifras significativas y gráficas**, con ejercicios autocorregidos y un filtro por
nivel (2º / 3º-4º).

## Ver la app

Es una página única (`index.html`). Publicada con **GitHub Pages**:

👉 https://ccalmar2201-maker.github.io/calero-aula-fisica/

(También se puede abrir el `index.html` directamente en cualquier navegador, sin internet.)

## Contenido
- Conceptos iniciales (potencias y fracciones)
- Conversión de unidades (escalera de prefijos)
- Cambios de estado *(en preparación)*
- Notación científica · Cifras significativas *(3º/4º)*
- Construcción de gráficas
- Actividades interactivas y gimnasio de conversiones
